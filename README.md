# Ex 4 – Dynamic Background Colour Changer

Changes the page background dynamically using JavaScript: preset colour swatches, a colour picker, hex-code input with validation, random colours, random gradients, an automatic colour cycle with adjustable speed, copy-to-clipboard and a colour history. Press Space for a random colour.

## Run on Windows (one click)

Double-click **`setup.bat`**. It opens `index.html` in your default browser.
No installs needed – this exercise uses only HTML, CSS and JavaScript.

## Run anywhere else

Open `index.html` in any modern browser.
